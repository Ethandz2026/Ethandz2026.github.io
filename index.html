Hi, I'm Ethan — a developer building self-hosted dev infrastructure. This is my homelab: three physical machines wired into one remotely orchestrated cluster over MCP.

ABOUT

把 Agent 当作团队成员

在我这里，Agent 不是聊天窗口，而是能读写文件、跑命令、管理服务的同事。我搭建了一个跨三台实体电脑的 Agent 集群：一个统一入口，按需把任务派到 Windows 台式机、ThinkBook 和 Linux 笔记本上执行。

AGENT CLUSTER

三机集群拓扑

AI 编排层通过 MCP（Model Context Protocol）发起调用，经边缘聚合网关鉴权与路由，再沿各自的加密隧道抵达三台机器。每一跳都带独立令牌，机器本身不开放任何入站端口。

NODE 01 · WINDOWS 11

ETHAN 台式机

集群的部署中枢：网关代码、发布工具都在这里。负责重计算与本地模型。

NODE 02 · WINDOWS

Lenovo ThinkBook

随身节点，登录即自动拉起网关与隧道，出门也在集群里。

NODE 03 · ARCH LINUX

Xiaomi · Omarchy

Linux 常驻节点，systemd 用户服务 + linger，无人登录也保持在线。

STACK

用到的东西

全部基于开放协议与免费基础设施，零入站端口，令牌逐跳隔离。
